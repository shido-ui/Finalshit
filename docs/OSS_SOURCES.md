# Open-source acceleration sources

Potential implementation/reference sources:
- LawnchairLauncher/lawnchair — launcher implementation research.
- android/enterprise-samples — Android enterprise/device-management patterns.
- VikParuchuri/marker — document/PDF extraction research.
- android/architecture-samples — Android architecture and testing patterns.
- tiangolo/full-stack-fastapi-template — FastAPI backend structure and operational patterns.

Before copying source code into this repository, verify the source repository's current license and preserve required notices. Marker and Lawnchair require particular license review before code or model assets are redistributed.

FocusForge-specific code is original unless a file explicitly states otherwise.
